# Mirogate Boundary — دليل البدء بالعربية

[English documentation](README.md) · [إعداد النموذج المحلي](docs/model-setup.md) · [نتائج التقييم](docs/evaluation.md) · [نموذج التهديدات](docs/threat-model.md)

أداة مفتوحة المصدر لفحص النص محلياً وتطبيق سياسة على البيانات التي تُكتشف فيه، قبل إرسال طلبات الذكاء الاصطناعي عبر وسيط محدد. تتضمن مجموعة اختبارات تركز على العربية والنصوص المختلطة.

**الإصدار v0.1 تجريبي وموجّه للمطورين، وليس ضماناً أمنياً.** قد يفوت الكاشف اسماً أو سراً أو معلومة يمكن استنتاجها من السياق. مرور الطلب لا يعني خلوّه من البيانات الحساسة. ابدأ ببيانات اصطناعية.

## ماذا يفعل؟

- يفحص ملفات النص وبيانات الإدخال، أو الرسائل النصية التي تمر عبر الوسيط المحلي.
- يطبق سياسة تسمح بالبيانات المكتشفة أو تستبدلها أو تمنع الطلب، حسب الفئة. اكتشاف سرّ يمنع الطلب دائماً في هذا الإصدار.
- يستبدل البيانات المكتشفة، وفق السياسة الافتراضية، بمعرّفات عشوائية مثل `<MB1_…>`، ويحتفظ بربطها بالقيم الأصلية في الذاكرة ضمن حدود للحجم والوقت.
- يمنع الإرسال عند فشل الكاشف؛ لا ينتقل بصمت من النموذج المحلي إلى القواعد وحدها.

هذا **استبدال بمعرّفات مستعارة قابلة للعكس**، وليس إخفاءً مضموناً للهوية. تبقى القيم الأصلية قابلة للاسترجاع عبر الربط المحلي، وقد تكشف المعلومات المتبقية أو السياق عن الشخص.

## تجربة محلية دون تنزيل نموذج

تحتاج إلى Git وPython 3.11 أو أحدث. نفّذ أولاً:

```sh
git clone https://github.com/mirogate/mirogate-boundary.git
cd mirogate-boundary
python -m venv .venv
```

فعّل البيئة الافتراضية بالأمر المناسب لنظامك:

```powershell
# Windows PowerShell
.\.venv\Scripts\Activate.ps1
```

```sh
# Linux / macOS
source .venv/bin/activate
```

ثم ثبّت الحزمة وافحص المثال الاصطناعي:

```sh
python -m pip install -e .
boundary scan --detector rules --file examples/contact.txt
python examples/capture_demo.py
```

الخيار `--detector rules` يختار القواعد المحدودة صراحةً؛ لا ينزّل نموذج ذكاء اصطناعي ولا يشغّله. تتعرف القواعد على بعض الأنماط المنظمة، لكنها لا تكفي لكشف الأسماء والمعلومات الشخصية في مختلف السياقات.

التجربة الأخيرة تستخدم مزوّداً وهمياً يعمل محلياً، وتعرض النص الذي وصل إليه فعلاً وتتحقق من استرجاع القيم محلياً. لا تستدعي أي مزوّد ذكاء اصطناعي خارجي. النص الذي يعرضه أمر الفحص قد يظل حساساً؛ لا تفترض أنه صالح للتسجيل أو النشر.

## النموذج المحلي والوسيط

يمكن إعداد OpenAI Privacy Filter محلياً، ثم استخدامه وحده أو دمجه مع القواعد. الوضع الافتراضي هجين ويتطلب إعداد النموذج؛ اتبع [تعليمات التنزيل والإعداد](docs/model-setup.md). التنزيل خطوة صريحة ومنفصلة؛ لا يُرسل نص المستخدم إلى خدمة كشف مستضافة. الكاشف المحلي نفسه قد يخطئ.

يدعم الوسيط جزءاً محدوداً من `/v1/chat/completions`: رسائل نصية غير متدفقة بأدوار `system` و`developer` و`user` و`assistant`. يرفض البث المتدفق، والأدوات واستدعاءاتها، والوسائط، وحقول الطلب غير المدعومة. لا يفحص ملفات PDF أو الصور أو اتصالات MCP العامة.

استرجاع القيم في الرد معطّل افتراضياً. عند تفعيله، يقتصر على النص الظاهر في رسالة المساعد ومعرّفات الطلب نفسه؛ لا يسترجع معاملات أدوات قابلة للتنفيذ. يستخدم الوسيط خريطة جديدة لكل طلب، دون ذاكرة ربط بين الطلبات. يبقى النص المسترجع مخرجاً غير موثوق للنموذج.

**أي اتصال لا يمر عبر هذا الوسيط خارج نطاق حمايته.** ليس جدار حماية للجهاز ولا بديلاً لضبط اتصالات الشبكة. لا تعرض الوسيط على الإنترنت؛ اقرأ [دليل الوسيط](docs/proxy.md) و[نموذج التهديدات](docs/threat-model.md) قبل ربطه بتطبيق.

## كيف نقرأ الأدلة؟

تضم مجموعة التشخيص 99 حالة اصطناعية، و90 كياناً معلّماً، و18 حالة سلبية لا يفترض اكتشاف بيانات حساسة فيها. تشمل العربية واختلاف أشكال الأرقام ونصوصاً مختلطة وحالات Unicode، لكنها **ليست عينة ممثلة أو مجموعة اختبار محجوبة عن التطوير**، ولم تُراجع تعليقاتها يدوياً بشكل مستقل.

اقرأ [وصف البيانات والمقاييس](benchmarks/README.md) و[تقرير النتائج الفعلية](docs/evaluation.md). نجاح اختبارات الوسيط لا يثبت دقة الكاشف، ونتائج القواعد ليست نتائج النموذج. لا تمنح هذه الاختبارات شهادة أمان أو امتثال.

يمكن حفظ سجلات قرار دون القيم الأصلية أو النص المحوّل؛ تظل الأعداد والأطوال بيانات وصفية تستحق الحذر. التحقق من سلسلة السجلات يحتاج إلى بصمة نهائية محفوظة في مكان موثوق مستقل لاكتشاف إعادة كتابة السلسلة أو اقتطاعها.

## المساهمة

نرحب بأمثلة اصطناعية توضح حالات الإخفاق أو الاكتشاف الزائد، ومراجعة التعليقات العربية، وإعادة إنتاج النتائج. **لا تضع سجلات عملاء أو بيانات شخصية حقيقية أو مفاتيح نشطة في البلاغات أو طلبات التعديل.** أرفق مثالاً مخترعاً والنتيجة المتوقعة وإصدار الكاشف، وراجع [دليل المساهمة](CONTRIBUTING.md) و[سياسة الأمان](SECURITY.md).

الكود والمجموعة الاصطناعية مرخّصان بموجب Apache-2.0. يحتفظ النموذج وبيئة تشغيله بتراخيصهما الأصلية. المشروع مستقل عن OpenAI وليس معتمداً منها.
