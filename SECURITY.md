# Security policy

Boundary is experimental. Do not treat it as a complete data-loss-prevention system or deploy it as a public/shared gateway. Detector misses are expected; ordinary misses should be described using synthetic cases.

For a bypass of a documented enforcement control, use GitHub's **Report a vulnerability** private reporting option if it is available on this repository. If unavailable, open an issue requesting a private contact without including exploit details or sensitive data. Do not post live tokens, original customer records or private logs.

The supported release line is 0.1.x. There is no guaranteed response time or independent audit claim. Consult docs/threat-model.md before deployment.
